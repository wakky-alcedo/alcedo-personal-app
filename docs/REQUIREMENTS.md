# 要求仕様

## 機能要件

概要
本システムは，自己管理（タスク・習慣・信念）と外部連携（Obsidian・X・時間計測）を統合した「パーソナル・オペレーティング・システム」として機能します．

1. 信念
    - アプリの最初の画面に表示
    - Androidのホーム画面ウィジェット
    - リストの中からランダムに表示
2. タスク
	- やることリスト（ToDo）：CRUD操作，優先度設定，期限通知．
	- 短期やること（こちらを優先表示）
		- 今日やること
		- 買い物リスト
			- お店別
	- 長期やること
		- 行きたいところ
		- アニメ
		- メモ書きテーマ
3. 習慣管理機能
	- 習慣化トラッカー：実行ログの記録，継続日数の可視化（ストリーク機能）．
	- スマートフォンのロック画面やウィジェットで常に視界に入る設計．
4. Obsidian連携機能（非同期バッファ方式）
	- Shared Intent受領：他アプリの「共有」からテキスト・URLを取得し，即座にLocal DB (Room)へ保存．
	- 編集フェーズ：送信前にタイトルやタグ，追加コメントを編集するバッファ画面．
	- 後からも編集可能．
	- 同期トリガー（NFC/Location）：
		- NFCタグ検知：PCに貼ったNFCにタッチした際，未送信データを一括でLocal REST API経由でPCへ送信．
		- Wi-Fi SSID一致：自宅Wi-Fi接続時にバックグラウンドで同期試行．
	- 転送方式は，ObsidianのREST API（Local REST APIプラグイン）で，今日の日付のファイルの末尾に追加．
5. 行動計測・可視化機能
	- 情報収集方法
		- アプリ使用時間取得：AndroidのUsageStatsManager APIを利用し，カテゴリ別の利用時間を自動収集
		- PCの使用時間：PC側でRescueTime等のアクティビティトラッキングツールを利用し，カテゴリ別の利用時間を収集
            - PCとスマホの時間を合算して分析
		- Googleマップの履歴
		- Googleカレンダーとも同期
		- HomeAssistantの在宅検知、消灯検知も利用し、睡眠時間の計測
		- 手動計測（ポモドーロ等）：特定のタスクに対する工数計測
	- ダッシュボード：1日の時間配分を円グラフ等で可視化．
6. Twitter（X）投稿代行
	- 将来的に実装

## 画面遷移と配置設計
アプリは以下の5画面構成を基本とします．

1. ダッシュボード（メイン画面）
上部：信念エリア

最も重要な信念を大きなフォントで表示．タップで編集画面へ．

中央：時間使用率（円グラフ）

「今日何に時間を使ったか」をリアルタイム可視化．

下部：習慣クイックチェック

当日の主要な習慣3つ程度を1タップで完了処理．

2. Obsidianバッファリスト
構成：カード形式のリスト．

要素：取得元アプリ名，取得日時，テキスト本文プレビュー，送信ステータス（未送信/待機中）．

操作：スワイプで削除，タップで編集，右下フローティングボタンで新規手動メモ．

3. タスク・習慣管理詳細
構成：タブ切り替え（ToDo / Habit）．

Habitタブ：カレンダービュー（ヒートマップ形式）を表示し，継続状況を一目で確認．

4. 分析レポート
構成：週次/月次の棒グラフ．

データ：スマホ使用時間 vs 学習時間の比率を表示し，時間の浪費を警告．

5. 設定・外部連携
NFC設定：特定のTag IDを本アプリに関連付け．

API設定：X API (Bearer Token)，Obsidian (Local REST API Key/Port)．

## 非機能要件
- PCでも利用可能なクロスプラットフォーム対応
- パフォーマンス：アプリ起動は3秒以内，Obsidianへのデータ送信は5秒以内に完了させること．
