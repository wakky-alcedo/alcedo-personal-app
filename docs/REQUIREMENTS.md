# 要求仕様

## 機能要件

概要
本システムは，自己管理（タスク・習慣・信念）と外部連携（Obsidian・X・時間計測）を統合した「パーソナル・オペレーティング・システム」として機能します．

1. 信念
    - アプリの最初の画面に表示
    - Androidのホーム画面ウィジェット
    - リストの中からランダムに表示
2. タスク
	- やることリスト（ToDo）：CRUD操作，優先度設定，期限通知．
	- サブタスク：各タスクにツリー構造のサブタスクを持てる（再帰的にネスト可）．保存時に空タイトルのサブタスクは自動除去．
	- ステータス・優先度フィルタ：一覧をステータス（todo/doing/done/all）および優先度（high/medium/low/all）で絞り込み可能．フィルタ状態はlocalStorageに永続化．
	- ソート：優先度・期限・更新日時でソート可能．ソート設定はlocalStorageに永続化．
	- 期限の色分け表示：カード背景を期限までの残日数で色分け（今日＝赤，3日以内＝橙，7日以内＝黄，期限切れ＝薄表示）．
	- 期限時刻：トップレベルタスクは日付に加えて時刻（HH:mm）を任意設定可能．日付未設定時は時刻欄も無効化．
	- Web通知（実装済み）：dueAt・dueTime両方設定済みかつ未完了のタスクについて，期限の指定分前（デフォルト30分，設定画面で変更可）にブラウザ通知（許可時）またはアプリ内通知で知らせる．通知のON/OFFも設定画面で切り替え可能．
	- Android通知（実装済み）：Web通知と同じ条件・タイミングでローカル通知を表示．設定画面で「通知を有効化」「何分前に通知」「アラーム音を鳴らす」を個別にON/OFF・変更可能（いずれもデフォルトOFF/30分）．アラームONの場合は音・バイブ付きの通知チャンネルを使用．
	- 詳細欄のURLはCtrl+クリックでブラウザ表示可能．
	- SSEによるリアルタイム同期：サーバーがイベントをプッシュするたびに一覧を自動更新．
	- 短期やること（こちらを優先表示）
		- 今日やること
		- 買い物リスト
			- お店別
	- 長期やること
		- 行きたいところ
		- アニメ
		- メモ書きテーマ
3. 習慣管理機能
	- 習慣化トラッカー：実行ログの記録，継続日数の可視化（ストリーク機能）．
	- 習慣ヒートマップ：過去の達成状況をカレンダー形式のヒートマップで表示．
	- 各習慣に対して，通知時刻およびウィジェットで優先的に表示される時間帯を設定できるようにする．
	- スマートフォンのプッシュ通知やウィジェットで常に視界に入る設計．
	- プッシュ通知では，その場で「完了」や「後で」を選択できるようにする．
4. メモ機能（Phase1実装済み）
	- 記事共有からメモ作成：他アプリの「共有」（テキスト/URL）でAlcedoを選ぶと，記事URLプレビューとコメント入力のBottomSheetが開く．
	- メモ一覧：全文表示（省略なし），URLはドメイン+タイトルのプレビューカードを自動表示（クリックで該当ページを開く），本文中のURL文字列もタップ/クリックで該当ページを開く，作成日時を小さく表示，時系列（新しい順）で並べる．
	- 編集：本文エリアをクリックするとカード内でインライン編集モードに切り替わる（BottomSheetではなくカード内textarea）．フォーカス離脱で自動保存，Escで変更破棄．
	- コピー：各カード右上のアイコンボタンでメモ本文・記事タイトル・記事URLを改行区切りでクリップボードにコピー．
	- 削除：Webは削除ボタンで確認後削除．Androidはカードを左にスワイプすると削除アイコンが現れ，タップで削除（Snackbarで元に戻せる）．
	- リアルタイム同期（双方向）：Android → PC はWorkManager OneTime Push，PC → Android は15分間隔PeriodicWork Pull．
	- 競合解決：`version` フィールドで楽観的排他制御（Taskと同方式）．
5. Obsidian連携機能（非同期バッファ方式）
	- Phase2以降で実装（当面は後回し）
	- Shared Intent受領：他アプリの「共有」からテキスト・URLを取得し，即座にLocal DB (Room)へ保存．
	- 編集フェーズ：送信前にタイトルやタグ，追加コメントを編集するバッファ画面．
	- 後からも編集可能．
	- 同期トリガー（NFC/Location）：
		- NFCタグ検知：PCに貼ったNFCにタッチした際
		- Wi-Fi SSID一致：自宅Wi-Fi接続時
	- 転送方式は，要検討．できれば，obsidianのgitに直接commitするか，サーバーPC側でcommitする．
    - 同期失敗時
        - 重複送信防止（同一メモの二重追記防止）は，メモID管理で実装
5. 行動計測・可視化機能
	- 情報収集方法
		- アプリ使用時間取得：AndroidのUsageStatsManager APIを利用し，カテゴリ別（初期テンプレートを用意し，一部ユーザー編集可能）の利用時間を自動収集
		- PCの使用時間：win-tracker（PC側常駐アプリ）がアクティブウィンドウを記録し，カテゴリ別の利用時間を収集
            - PCとスマホの時間を合算して分析
            - 複数デバイスをデバイスIDで区別し，フィルタ表示可能
		- Googleマップの履歴
		- Googleカレンダーとも同期
		- HomeAssistantの在宅検知、消灯検知も利用し、睡眠時間の計測
		- 手動計測（ポモドーロ等）：特定のタスクに対する工数計測
	- 分析ダッシュボード
		- 日次：24時間タイムライン（睡眠区間含む），作業時間配分（円グラフ），タイムライン詳細リスト
			- 作業時間配分はバケツマージ後の時間を使用（複数デバイス重複を排除）。不明・睡眠を除いた実活動のみ集計
			- 睡眠時間は合計の下に「睡眠: Xh」として別表示。win-tracker 自動検出と手動入力を統合
		- 日次（手動記録）：開始〜終了時刻で記録（カテゴリ選択・CRUD）。記録は自動記録タイムラインを上書きして反映
			- 日付境界（6am）をまたぐエントリはタイムラインにクランプ表示し、作業時間配分には含めない
			- 睡眠エントリは当日 effective day 内に終わるセッションの全時間を睡眠表示に反映（cross-boundary 分も含む）
			- 時間配分円グラフ，目標達成率，記録追加フォーム（インライン編集・削除対応）
		- 週次・月次：カテゴリ別積み上げ棒グラフ
	- 目標達成率：カテゴリごとの目標時間を設定し，達成率をバーで表示（実装済み）
	- 時間の浪費を警告（例：SNS使用時間が60分以上）
	- カテゴリ管理：カテゴリ色の設定，分類ルール（パターンマッチ）の管理
		- 分類ルールとカテゴリ色はJSONでエクスポート・インポート可能
	- アクティブタブバナー：win-trackerと連携し，PCで現在使用中のウィンドウタイトルをダッシュボードにリアルタイム表示
6. Twitter（X）投稿代行
	- 将来的に実装

## 画面構成

### PC Web App（3タブ構成）

1. **ダッシュボード**
	- アクティブタブバナー（現在使用中のPCウィンドウ）
	- 信念エリア（コンパクト表示：ランダムに1件）
	- 習慣クイックチェック（コンパクト表示：当日習慣を1タップ完了）
	- タスク一覧（フィルタ・ソート付き，インライン編集対応）

2. **分析**
	- 日次 / 週次 / 月次タブ切り替え
	- 日次：作業記録サブタブ（24hタイムライン・円グラフ・タイムライン詳細）と手動記録サブタブ
	- 週次・月次：積み上げ棒グラフ

3. **設定**
	- サーバーURL・APIキー設定
	- 信念管理（フルCRUD）
	- 習慣管理（フルCRUD＋ヒートマップ）
	- 分類ルール・カテゴリ色管理（エクスポート・インポート含む）

### Android App（5画面構成）

1. ダッシュボード（メイン画面）：信念・習慣クイックチェック・タスク一覧
2. Obsidianバッファリスト（Phase2）
3. タスク・習慣管理詳細
4. 分析レポート
5. 設定・外部連携

## 非機能要件
- プラットフォーム：Android，PC(Webアプリ)
- パフォーマンス：アプリ起動は3秒以内
- ユーザーアカウント：単一ユーザー前提
- 端末間同期：スマホとPC間でのデータ同期は必須
- 手動同期：Androidのダッシュボード・タスク・メモ画面では、リストを下方向にスワイプ（Pull to Refresh）するとPCサーバーとの同期を即時実行できる
- セキュリティ：APIキーは暗号化して保存し、外部に漏洩しないようにすること．
- ダークモード：OSの設定（prefers-color-scheme）に自動追従

## 保留事項
- Obsidian連携の完了定義（PC受信ACKまで / Vault追記完了まで / Git commit完了まで）は、Phase2着手時に決定する
- X投稿代行のMVPでの表示/非表示方針は後回しで決定する
