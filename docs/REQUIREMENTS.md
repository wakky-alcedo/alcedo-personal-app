# 要求仕様

## 機能要件

概要
本システムは，自己管理（タスク・習慣・信念）と外部連携（Obsidian・X・時間計測）を統合した「パーソナル・オペレーティング・システム」として機能します．

1. 信念
    - アプリの最初の画面に表示
    - Androidのホーム画面ウィジェット
    - リストの中からランダムに表示
2. タスク
	- やることリスト（ToDo）：CRUD操作，優先度設定，期限通知．
	- サブタスク：各タスクにツリー構造のサブタスクを持てる（再帰的にネスト可）．保存時に空タイトルのサブタスクは自動除去．
	- ステータス・優先度フィルタ：一覧をステータス（todo/doing/done/all）および優先度（high/medium/low/all）で絞り込み可能．フィルタ状態はlocalStorageに永続化．
	- 期限の色分け表示：カード背景を期限までの残日数で色分け（今日＝赤，3日以内＝橙，7日以内＝黄，期限切れ＝薄表示）．
	- 詳細欄のURLはCtrl+クリックでブラウザ表示可能．
	- 短期やること（こちらを優先表示）
		- 今日やること
		- 買い物リスト
			- お店別
	- 長期やること
		- 行きたいところ
		- アニメ
		- メモ書きテーマ
3. 習慣管理機能
	- 習慣化トラッカー：実行ログの記録，継続日数の可視化（ストリーク機能）．
	- 各習慣に対して，通知時刻およびウィジェットで優先的に表示される時間帯を設定できるようにする．
	- スマートフォンのプッシュ通知やウィジェットで常に視界に入る設計．
	- プッシュ通知では，その場で「完了」や「後で」を選択できるようにする．
4. Obsidian連携機能（非同期バッファ方式）
	- Phase2以降で実装（当面は後回し）
	- Shared Intent受領：他アプリの「共有」からテキスト・URLを取得し，即座にLocal DB (Room)へ保存．
	- 編集フェーズ：送信前にタイトルやタグ，追加コメントを編集するバッファ画面．
	- 後からも編集可能．
	- 同期トリガー（NFC/Location）：
		- NFCタグ検知：PCに貼ったNFCにタッチした際
		- Wi-Fi SSID一致：自宅Wi-Fi接続時
	- 転送方式は，要検討．できれば，obsidianのgitに直接commitするか，サーバーPC側でcommitする．
    - 同期失敗時
        - 重複送信防止（同一メモの二重追記防止）は，メモID管理で実装
5. 行動計測・可視化機能
	- 情報収集方法
		- アプリ使用時間取得：AndroidのUsageStatsManager APIを利用し，カテゴリ別（初期テンプレートを用意し，一部ユーザー編集可能）の利用時間を自動収集
		- PCの使用時間：PC側でRescueTime等のアクティビティトラッキングツールを利用し，カテゴリ別の利用時間を収集
            - PCとスマホの時間を合算して分析
		- Googleマップの履歴
		- Googleカレンダーとも同期
		- HomeAssistantの在宅検知、消灯検知も利用し、睡眠時間の計測
		- 手動計測（ポモドーロ等）：特定のタスクに対する工数計測
	- ダッシュボード：1日の時間配分を円グラフ等で可視化．
	- 時間の浪費を警告（例：SNS使用時間が1時間以上）
	- 日次レポートおよび目標達成率は Phase2 で実装
6. Twitter（X）投稿代行
	- 将来的に実装

## 画面遷移と配置設計
アプリは以下の5画面構成を基本とします．

1. ダッシュボード（メイン画面）
上部：信念エリア（コンパクト表示）

アクティブな信念からランダムに1件を表示．

中段：習慣クイックチェック（コンパクト表示）

当日の主要な習慣3つ程度を1タップで完了処理．

下部：タスク一覧

フィルタ・ソート付きのタスクカード一覧．インラインでサブタスク編集・done切り替え・優先度変更・期限設定が可能．

2. Obsidianバッファリスト
構成：カード形式のリスト．

要素：取得元アプリ名，取得日時，テキスト本文プレビュー，送信ステータス（未送信/送信中/送信済/失敗/再試行中）

操作：スワイプで削除（確認は出す），タップで編集，右下フローティングボタンで新規手動メモ．

3. タスク・習慣管理詳細
構成：タブ切り替え（ToDo / Habit）．

Habitタブ：カレンダービュー（ヒートマップ形式）を表示し，継続状況を一目で確認．

4. 分析レポート
構成：週次/月次の棒グラフ．

データ：スマホ使用時間 vs 学習時間の比率を表示し，時間の浪費を警告．

5. 設定・外部連携
サーバー接続：サーバーURL・APIキーの設定．
信念管理：信念のフルCRUD（ダッシュボードではコンパクト表示のみ）．
習慣管理：習慣のフルCRUD＋チェックイン（ダッシュボードではコンパクト表示のみ）．
NFC設定：特定のTag IDを本アプリに関連付け．
Wi-Fi設定：特定のSSIDを自宅と認識するように設定．

## 非機能要件
- プラットフォーム：Android，PC(Webアプリ)
- パフォーマンス：アプリ起動は3秒以内
- ユーザーアカウント：単一ユーザー前提
- 端末間同期：スマホとPC間でのデータ同期は必須
- Phase1の同期対象：タスク（最小構成，Android -> PC の片方向同期）
- 将来的に PC -> Android を追加し，双方向同期へ拡張する
- セキュリティ：APIキーは暗号化して保存し、外部に漏洩しないようにすること．

## 保留事項
- Obsidian連携の完了定義（PC受信ACKまで / Vault追記完了まで / Git commit完了まで）は、Phase2着手時に決定する
- X投稿代行のMVPでの表示/非表示方針は後回しで決定する
